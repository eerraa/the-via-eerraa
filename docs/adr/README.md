# Architecture decision records

Use this directory for decisions that materially affect protocol compatibility, persistent data, cross-repository responsibilities, deployment, licensing, or other architecture that future work must preserve.

Keep each ADR concise:

```text
# NNNN — Decision title
Status: Proposed | Accepted | Superseded

## Context
What verified constraint or failure requires a decision?

## Decision
What is being selected, including its boundary?

## Consequences
What becomes easier, harder, compatible, or intentionally deferred?

## Verification
How will the decision be tested or invalidated?
```

Do not use ADRs for branch status, process IDs, routine implementation details, or speculative options without a decision. Link accepted ADRs from `docs/PROJECT_DIRECTION.md` when they become part of the durable project direction.
